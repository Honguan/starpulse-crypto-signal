| 問題 | 修改與驗證 |

| 「全部」實際只有 5 筆 | 更名「精選 5 筆」，新增真正的全部模式及結果數；操作回歸覆蓋 |
| 中文、空格與連字號搜尋被破壞 | 搜尋與收藏共用比對，只正規化 USDT 代號；涵蓋中文／CoinGecko ID 測試 |
| 缺少方向篩選與排序 | 加入多／空／觀望、市值及漲跌幅排序；使用快照維持穩定位置 |
| 收藏按鈕無回饋或寫入失敗就中止 | 精確匹配才允許加入，顯示收藏數；儲存失敗保留本次選擇並提示 |
| 首次讀取失敗後永遠不再更新 | 不論第一次成功與否均建立更新排程；測試涵蓋失敗後恢復 |
| 讀取可無限等待、不能手動重試 | 加入 15 秒請求上限、重新整理、busy 狀態與請求防重入 |
| 兩次網路更新之間仍顯示舊資料狀態 | 每 30 秒檢查快照年齡，返回頁面或網路恢復時重試；測試過期停用 |
| 卡片重繪會關閉正在閱讀的圖表 | 保留仍可見卡片的 details 展開狀態，延續既有焦點恢復 |
| K 線不足時永久顯示等待載入 | 提供無資料說明、隱藏空 canvas、明示失敗後的重試操作；測試空圖表 |
| 觀望可能誤用做多 RR | 只有有效主要方向才顯示主要 RR；renderer 回歸涵蓋 |
| miniTicker 漲跌幅永不更新 | 改用實際 c/o 欄位計算；以真實訊息形狀驗證 |
| 即時狀態、方向徽章與 RR 不一致 | 共用既有主要方向判定，雙向有效轉觀望，狀態恢復時同步 RR |
| 窄卡難以比較、重複警語過長 | 改為較寬的兩欄計畫卡、手機單欄；詳細依據／警語可展開 |
| 缺少單位與操作引導 | 價格標明 USD、區分行情／快照、清楚說明條件分數不是勝率 |
| 資料降級原因不明 | 市場摘要顯示成功／失敗／缺歷史數；保留新鮮度與來源 |
| 歷史不足被誤標為低風險 | 無有效波動率時沿用現有市場風險規則；涵蓋高／中／低回歸案例 |
| 成功回應的本體逾時不重試 | 將本體傳輸納入網路／逾時重試，僅 JSON 語法錯誤不重試 |
| 策略說明焦點重繪後移到 K 線 | 分別恢復圖表／策略說明的 summary 焦點；操作回歸涵蓋 |
